# Aimbot tuning

The default `fov = 8.0` and `smooth = 3.2` are tuned for 1080p, 800 DPI.
If you're on 1440p, scale FOV linearly: `fov_1440 = fov_1080 * 1440 / 1080`.

## Bone targets
- `head` — highest accuracy, most detectable
- `neck` — balanced
- `spine2` — least detectable

## Silent vs smooth
Set `smooth = 1.0` for silent (instant snap). Not recommended on live servers.
